# Bằng chứng QA

Châu quản lý. Mỗi file ghi commit/schema/device, command, expected, actual và người xử lý nếu fail.
Không lưu token, SECRET_KEY, .env hoặc dữ liệu riêng tư.

- `PREPARATION_CHECK.md`: kết quả kiểm tra bộ khung do bước chuẩn bị ghi lại.
- `TV4_CP1.md`: bằng chứng auth/accounts và nền backend của LB.
- `TV4_CP2_CP3.md`: bằng chứng thị trường/watchlist/tài sản và tích hợp giao dịch của LB.
- `environment.md`: Châu tạo khi xác nhận ENV-01 trên máy nhóm.
- `bugs.md`: Châu tạo khi phát hiện bug đầu tiên; dùng mẫu ở team/TV6_CHAU.md.
- `demo.md`: Châu tạo ở chặng 3; bước demo và vị trí APK, ảnh/log.

Các tên chưa tồn tại ở trên là đầu ra của task tương ứng, không phải kết quả đã có.
